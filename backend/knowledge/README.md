# Business notes for the AI

Put plain-text notes here (`.md` or `.txt`). The office's AI reads every file in this folder
(except this README) on each task, so edits apply right away without a restart. You can edit
these files in any text editor, including Obsidian.

Good things to add:

- `prices.md`: door and furniture prices, wood types, finishes, add-ons (hamba, varnish). Marco
  only quotes prices that appear here.
- `policies.md`: downpayment rules, lead times, delivery and installation areas, warranty.
- `style.md`: how WAD writes captions and customer replies, with two or three real examples.
- `team.md`: who handles what, crew sizes, working days.

Keep it short and factual. The total is capped at about 24,000 characters per task.
**Don't put passwords, API keys, or customers' personal details here.** These notes are sent to
the AI provider with every task.
